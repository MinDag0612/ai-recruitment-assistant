# **AI Recruitment Assistant**

## **Problem:**

Candidates often don't know if their CV matches the job description. This project is create to support user that easily get a match score between CV and JD for a job.

## Target:

Build an AI-powered recruitment assistant that demonstrates: 

*   AI integration 
*   Backend engineering 
*   Clean API design 
*   Production-ready architecture

**Non-goal**

*   Build a complete ATS
*   Compete with LinkedIn 
*   Train an AI model

## **User:**

Candidates

## **Code feature:**

*   Upload CV.
*   Upload JD (multiple mode).
*   AI scoring.
*   Sample interview question.
*   Store CV
